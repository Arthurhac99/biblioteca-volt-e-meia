# Modelagem de Sistemas Dinâmicos 1 e 2

!!! note "Mudança na grade"
    **Modelagem 1** substitui a antiga **Equações Diferenciais B**.

Transformar um sistema físico (mecânico, elétrico, térmico, hidráulico) em equações e simular o comportamento dele.

| Linearização | A fazer |
| Simulação numérica (MATLAB, Simulink, Python) | A fazer |
